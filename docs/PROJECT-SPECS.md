# AI Projects for Students

## 1. Resume Analyzer

- Goal: score a resume against a job description and suggest improvements.
- Stack: Next.js, Python/FastAPI, embeddings, PostgreSQL.
- AI concept: semantic similarity, extraction, ranking.
- Recruiter signal: practical NLP, product thinking, useful UI.

## 2. Campus Doubt Solver

- Goal: answer questions from uploaded notes, PDFs, and previous-year papers.
- Stack: React, FastAPI, vector database, OCR.
- AI concept: retrieval augmented generation.
- Recruiter signal: RAG architecture, document processing, evaluation.

## 3. Interview Feedback Coach

- Goal: transcribe mock interviews and provide structured feedback.
- Stack: Whisper-compatible transcription, LLM feedback, dashboard.
- AI concept: speech-to-text, rubric scoring, summarization.
- Recruiter signal: multimodal pipeline and measurable output.

## 4. GitHub Profile Reviewer

- Goal: audit a GitHub profile for recruiter readiness.
- Stack: GitHub API, scoring rules, static report generation.
- AI concept: summarization and recommendation generation.
- Recruiter signal: developer tooling and API integration.

## Evaluation Checklist

- Add a real demo.
- Show sample input and output.
- Include limitations.
- Track precision/recall or human rubric scores where possible.
